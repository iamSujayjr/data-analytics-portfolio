## Project Overview

<img width="800" height="449" alt="Red_ball" src="https://github.com/user-attachments/assets/ec81ad11-15d9-4cce-985d-e981fec7be2a" />


Red Ball Intelligence is an end-to-end Test Cricket analytics dashboard built using Power BI and Python.

The project explores:
- overall team performance
- opponent-wise analysis
- overseas SENA challenges
- long-term era evolution

The dashboard focuses on transforming raw match-level cricket data into meaningful analytical storytelling through interactive visualizations and performance metrics.

## Dashboard Features

### Page 1 — Team Performance Overview
- Overall win/loss/draw analysis
- Home vs Away performance
- Match trends over time
- Dynamic country filtering

### Page 2 — Opponent Analysis
- Opponent-wise win percentages
- Rivalry landscape visualization
- Performance distribution against teams
- Scatter plot difficulty analysis

### Page 3 — India in SENA Conditions
- Overseas SENA performance analysis
- Country-wise SENA breakdown
- Trend evolution in difficult conditions
- Result composition analysis

### Page 4 — Era & Performance Evolution
- Long-term performance trends
- Home vs Away evolution
- Rolling performance trends
- Era dominance and transition insights

## Key Insights

- India’s overseas SENA performance improved significantly during the late 2010s.
- Australia and South Africa emerged as the toughest overseas conditions.
- Modern Test cricket shows a noticeable reduction in draw percentages.
- Home dominance remained relatively stable across most eras, while away adaptability evolved gradually.
