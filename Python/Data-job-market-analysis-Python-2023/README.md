# 📊 Data Job Market Analysis (Python)

## 📌 Project Overview

This project analyzes a large dataset of job postings (700k+ rows) to uncover trends and insights in the global data job market.

The analysis focuses on:

* job demand
* salary distribution
* role popularity
* country-wise opportunities
* experience-level impact on salary

Using Python and data analysis libraries, the project transforms raw job posting data into meaningful analytical insights and visualizations.

---

## 🎯 Objectives

* Identify the most common data-related roles
* Analyze salary distribution across job titles
* Understand demand by country
* Explore the relationship between experience level and salary
* Discover trends in the global data industry

---

## 🛠 Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Analysis Performed

### 1️⃣ Job Role Distribution

* Most in-demand data roles
* Top hiring positions
* Role frequency analysis

### 2️⃣ Salary Analysis

* Salary distribution across roles
* Average and median salary comparison
* Salary outlier detection

### 3️⃣ Country-Wise Demand

* Countries with highest job demand
* Regional hiring trends
* Global opportunity distribution

### 4️⃣ Experience Level Analysis

* Salary growth by experience level
* Junior vs Senior role comparison
* Entry-level market trends

---

## 📈 Key Insights

* Data Analysts and Data Engineers are among the most in-demand roles.
* Senior-level positions show significantly higher salary ranges.
* Certain countries dominate global hiring demand.
* Salary distributions contain noticeable outliers in high-paying technical roles.
* Experience level has a strong positive relationship with salary growth.
